# Adityaraj Patil — Portfolio

A modern, interactive personal portfolio website for **Adityaraj Patil** — a full-stack developer, author, AI enthusiast, researcher, inventor, and entrepreneur.

## Live Website

- Portfolio: https://patiladityaraj.netlify.app/
- GitHub: https://github.com/aspatil0
- LinkedIn: https://linkedin.com/in/adityarajpatil/
- Amazon Author Page: https://amazon.com/author/adityarajpatil

## Features

- Responsive portfolio design
- Light and dark theme support
- Interactive project filtering
- Animated hero section
- Custom cursor and scroll animations
- Projects showcase
- Books and publications library
- Patents and research papers section
- Interactive technology toolkit
- Professional journey timeline
- Contact section
- Resume download
- Mobile navigation menu
- Background particle/network animation
- Audio player with playlist
- Accessibility support with skip navigation and reduced-motion handling
